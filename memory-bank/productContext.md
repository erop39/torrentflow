# Product context

The user needs a compact, dark NAS control room rather than a general torrent client. The main flow is: add RSS feed → create rule → inspect decisions → optionally add to qBittorrent → receive Telegram event → inspect audit history.

UX direction: Obsidian Flux. Use dense but calm operational layouts, clear empty/error states, compact aligned controls, Lucide icons, and category colors as secondary markers. Every destructive action needs confirmation. The dashboard must distinguish healthy, degraded, and unconfigured services in text as well as color.
