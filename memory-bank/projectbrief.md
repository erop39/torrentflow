# Project brief

TorrentFlow is a LAN-first control room for monitoring RSS/Atom releases on a NAS, applying priority rules, notifying an administrator, and optionally adding matching releases to qBittorrent.

Target deployment: Synology-compatible Docker Compose, one local administrator, SQLite persistence. The web dashboard is the primary interface; Windows tray is a later phase.

Release goal: dependable RSS intake, explainable rule decisions, qBittorrent monitoring/auto-add, Telegram notifications, auditability, and safe local operation.
